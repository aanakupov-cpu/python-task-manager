# Python Task Manager

Консольный менеджер задач на Python: добавление задач, просмотр списка и отметка о выполнении.

## Структура проекта

    python-task-manager/
    ├── src/main.py
    ├── tests/test_main.py
    ├── README.md
    ├── requirements.txt
    └── .gitignore

## Запуск

    python3 src/main.py

## Тесты

    python3 -m unittest discover -s tests -v

## Ветки проекта

- `main` — основная стабильная версия
- `feature/add-function` — функция удаления задач
- `feature/improve-interface` — интерактивное меню
- `feature/documentation` — документация проекта
